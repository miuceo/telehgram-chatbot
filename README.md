# 🤖 Telegram Aqlli AI Boti

Ushbu bot **Google Gemini** sun'iy intellekti bilan ishlaydi va **100% bepul**.

Batafsil tushuntirish va o'rnatish qo'llanmasi uchun **[QOLLANMA.md](QOLLANMA.md)** fayliga qarang.

### Tezkor ishga tushirish:
1. `.env` fayliga `TELEGRAM_BOT_TOKEN` va `GEMINI_API_KEY` kalitlarini kiriting.
2. `ishga_tushirish.bat` faylini ikki marta bosing.
